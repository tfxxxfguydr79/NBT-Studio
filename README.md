# NBT Studio (Beta 1.2)

A simple editor for Minecraft save data.

Edit players, inventories, enchantments, potion effects and world settings,
or open a whole world folder. Typing odd values only shows a warning and
never stops you from saving.

## Download

Go to Releases (on the right side of this page) and download the file for your system.

- Linux: extract the .tar.gz and double-click NBTStudio-Beta-1.2-linux-x64.
- Windows: coming soon.

## Supported versions

- Java 1.8 to 1.21.4: full support
- Java 1.21.5 and newer: experimental
- Java Alpha, Beta and 1.0 to 1.7: basic
- Bedrock level.dat: raw editing only

This is a beta. Keep a backup of worlds you care about.
